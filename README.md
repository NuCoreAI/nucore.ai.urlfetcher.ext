# NuCoreAI URL Fetcher Extension

This extension adds guarded URL fetching capabilities for NuCoreAI integrations.

## Overview

The URL Fetcher Extension is intended for workflows that need to retrieve content from external URLs while keeping the integration surface narrow and intentional.
